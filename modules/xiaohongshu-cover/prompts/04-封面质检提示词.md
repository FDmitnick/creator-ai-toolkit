# 封面质检提示词

> 上传封面图后复制发送。仅适用于支持图片理解的对话 AI。

```text
请按小红书封面点击率标准检查这张图。不要礼貌性夸奖，直接指出影响点击的问题。

分别给以下项目打 1—10 分，并说明原因：
1. 信息密度：缩略图下能否一眼看懂内容利益点；
2. 视觉锚点：是否有一个明确、最先被看到的主体；
3. 80px 缩略图可读性：主标题是否仍清楚；
4. 色彩对比：标题和背景是否足够区分；
5. 真实感与可信度：是否有假数据、假界面、杂乱小字等问题。

然后输出：
- 最大的问题；
- 最优先修改的 3 个地方；
- 应该删除的元素；
- 主标题是否需要缩短，以及更好的标题；
- 一份可直接重新生图的完整提示词。
```
