# 修改返工口令

> 将生成的封面上传到支持看图的 AI 后，任选一种口令发送。若图片模型不支持上传图片，也可把问题文字描述后发送。

## 修正文字

```text
请保持构图、人物、颜色和视觉风格不变，只修正封面文字。

封面必须准确显示：
主标题：“”
副标题：“”
角标：“”

不要添加任何其他文字、Logo、水印或 @账号。
```

## 更有点击欲

```text
请保持主题不变，把这张封面改得更适合小红书信息流点击：主标题更大、更短、更有利益点；只保留一个视觉锚点；提高标题与背景对比；删除不必要的小字和装饰。请输出完整重新生图提示词。
```

## 更干净高级

```text
请保留主题、标题和主视觉，把封面调整为更高级、克制、干净的版本：留白更多，颜色减少为两种主色加一种强调色，装饰减少，主标题保持最大最醒目。请输出完整重新生图提示词。
```

## 80px 缩略图修复

```text
请重做这张封面，使其通过 80px 缩略图测试：主标题缩小后仍然清楚；只有一个视觉锚点最突出；色彩对比更强；所有次要文字缩小或删除。请输出完整重新生图提示词。
```
