# 小白使用说明

## 你只需要会三件事

1. 把总提示词发送给一个对话 AI。
2. 填一张需求卡。
3. 将 AI 写好的“完整生图提示词”复制到图片生成工具。

## 推荐流程

```text
总提示词 → 填需求卡 → AI 出封面方案和生图提示词 → 图片工具出图 → 上传图片做质检 → 复制返工口令
```

## 用 DeepSeek 时

DeepSeek 没有生图功能也没关系：它负责想标题、选模板、写出图提示词；随后把“完整生图提示词”复制给你能使用的图片模型即可。

## 用豆包或其他带生图的对话 AI 时

在同一对话先发送总提示词和需求卡，再让它根据自己的“完整生图提示词”生成图片。若文字错了，使用“修正文字”返工口令。

## 常见问题

### AI 问了很多问题怎么办？

直接回答它提出的素材或标题问题即可。若希望它别追问，在需求卡最后加：`信息不足时请自行做合理设计判断，不要追问。`

### 图片上的字总是错怎么办？

先让图片模型生成没有文字或只含主标题的版式，再用 Canva、醒图等工具手工叠加文字，通常更稳定。也可以先用“修正文字”口令重试一次。

### 封面看起来好看但没人点怎么办？

上传封面并使用“封面质检提示词”。重点检查：标题是否太长、有没有唯一视觉锚点、缩略图下是否还能看清。
