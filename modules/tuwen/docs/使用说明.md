# 图文｜短段落解释 + 数据配图

用平铺直述的中文短段落解释财经、商业和科技话题，配竖版数据图或关系图。正文讲逻辑，图片提供数字、比较与关系。默认白底、深蓝标题、浅蓝卡片，手机阅读优先。

## 普通对话 AI 使用

复制 [图文制作指令](../skill/SKILL.md) 和 [视觉规范](../skill/references/visual.md)，再填写下方需求卡。需要最新事实时使用可联网的平台；精确数值图表需要具备绘图或代码执行能力的工具。纯文字模型只能输出文案与配图方案，不能声称已经生成图片或核验来源。

## 极简需求卡

```text
主题：
已知材料或来源：
统计时间 / 比较窗口：
核心判断（可留空）：
输出：短段落文案 + 一张竖版解释图
配色：默认蓝白
```

## 已有文字快速整理

把原文贴给 AI，附上：

```text
按我的短行格式拆一下。
保留原意和用词，只整理断句、换行和分组。
同一意思紧接排列，换话题时空一行。
不要固定行长，不要逢逗号就换行，不新增问句或总结。
```

需要轻改时再加“顺便改顺”。默认不扩写、不自动制图；事实疑点在正文之外单列。风格示例见[发布配文参考](../skill/references/publishing-copy.md)。Codex 环境使用 human-writing 技能审读；普通聊天平台没有该技能时，按上述规则检查，不能声称已调用技能。

## Codex Skill 安装

将本模块的 `skill` 目录完整复制为 `~/.codex/skills/tuwen/`，保留 `SKILL.md`、`agents/`、`references/` 的目录结构。随后在 Codex 中调用 `$tuwen`。

## 三个使用示例

1. 中期选举：比较2006、2010、2014、2018、2022五轮选后一年SPY、QQQ、IWM的复权收益，并拆分两个半年。提供历史行情与计算口径后，再生成图文；不把五轮样本写成必然规律。
2. 公司财报：基于公司投资者关系网站的季度报告，解释收入、利润率和下一季指引。配图呈现实际值与同比变化，注明财季、币种和单位。
3. AI 算力：解释GPU采购、算力租赁合同与融资的关系。没有可靠数字时画关系图，区分已发生事实与条件推演，不编造数据。

## 边界与参考

输出文案、配图及来源说明，不自动发布到外部平台。准确图表优先采用标准绘图或矢量工具，交付前实际检查文字、数值与手机可读性。

参考帖仅用于理解通用表达与排版，不复制作者原文、署名或图片。本模块未收录第三方图片；参考链接见制作指令。仓库未单独声明本模块的开源许可证，不额外授予许可。
