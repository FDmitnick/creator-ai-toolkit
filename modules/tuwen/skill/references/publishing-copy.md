# 图文发布配文参考

用户在DeepSeek融资讨论中确认的风格，重点是材料选择和作者判断，不是照抄句式。仅在需要写这类发布配文时读取。

## 可复用的表达顺序

1. 先摆具体变化：六月刚融过一笔，几个月后又融一笔。
2. 接住一个真实疑点：基金业绩变差，能否解释模型公司融资？区分基金收益与管理公司现金，不编因果。
3. 集中解释主要去向：增加算力，以及产业股东可能提供的业务合作。
4. 名单服务于解释：互联网对应用户入口，制造对应业务应用，半导体投资机构对应产业链资源。这些是可能路径，不是已确认合同。
5. 用一个口径清楚的比较结束，不再补一段口号或重复摘要。

## 语气片段

> 一是DeepSeek要扩产，要更多的钱和更多的机器。
>
> 另一方面，下游业务方也想抢先一步合作。

第一句用具体动作解释资金需求。第二句体现作者的观察方向，但实际成稿需说明它是判断，或提供投资方表态支持；不能把希望合作的动机当作已核实事实。

这些片段只示范自然用词。段落长短、条目数量和是否编号服从当次请求，不固定写两点、六点或强制短行。

## 事实不能随风格一起复制

- “因为幻方亏钱才融资还真不是”：过度排除了未知因果。应依据证据写成“目前没有证据说明，这次融资是幻方亏钱造成的”。
- “与华为达成协议，弄16万颗”：如证据仅是媒体披露的部署计划，写“媒体报道计划部署至少16万颗昇腾”，不写成已采购或已交付。
- “差不多第二名Kimi的五倍”：先核实是否确为第二，再统一单轮、累计、币种与日期。案例中1000亿元与237亿元之比约4.2倍，不能沿用“五倍”。

本参考不提供可直接用于未来发布的最新事实或数字。保留说话方式，重新核实材料。

## 短行整理示例（仅演示格式）

输入：一是DeepSeek要扩产，要更多的钱和更多的机器。另一方面，下游业务方也想抢先一步合作，包括互联网、制造、汽车、半导体和纯资本。

整理：

```text
一是DeepSeek要扩产
要更多的钱和更多的机器

另一方面
下游业务方也想抢先一步合作
包括互联网、制造
汽车、半导体和纯资本
```

只调整换行与标点；保留“一是”“另一方面”等承接。这里沿用作者的说法示范排版，不构成对动机或行业分类的新增核实。事实疑点可在作品之外单列，不能借排版扩大判断。
