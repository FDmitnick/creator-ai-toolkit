# 蓝白图文视觉规范

默认方向源于用户已有「财报图文 Earnings」蓝白报表。下列色值是为本 skill 归一化选取的设计值，不是对原图的精确取色。

| 角色 | 默认色值 | 用法 |
|---|---|---|
| 背景 | #FFFFFF | 白底 |
| 标题 | #103A80 | 主标题、章节 |
| 正文 | #1F2937 | 常规说明，避免全文彩色 |
| 主强调 | #176BB3 | 关键柱、线、重要数字 |
| 卡片 | #EEF5FC | 小面积浅蓝底 |
| 分隔线 | #DCE5EF | 轻边框和表格线 |
| 次要文字 | #64748B | 来源与口径 |
| 压力或提醒 | #C65B32 | 少量异常项，附明确标签 |

涨跌方向遵循当前项目明确的惯例；未指定时用 +/− 和“上涨/下跌”文字表达，不让红绿或品牌色单独承担方向。橙色提醒也不自动等于下跌。

标题、图表和数字比装饰重要。全页保持一致边距、字体层级、卡片间隔；宽度约 5%—6% 作为左右边距起点。图片缩到手机宽度仍须可读，拥挤时先删重复内容或拆页。

单公司题目可改品牌强调色（例如红黑白），多公司/宏观/周报优先统一蓝白。用户可在之后调整默认主题，不把此次配色建议当作不可更改的要求。

正式财报双页系列可另行采用财报模板；本技能用于通用解释型图文，所需视觉规范已包含在本文件中，无需其他本机文件。
